Set up Chirp on your Mac

Build Chirp from source, download a speech model, grant two permissions and dictate into any app. About 15 minutes, most of it waiting for downloads. A packaged Mac app is coming soon; this is how you install it today.

Needs: macOS 14+, Apple Silicon or IntelUses: Terminal, once

Before you start

Chirp runs on macOS 14+ with Apple Silicon or Intel. Apple Silicon uses MLX (fastest); Intel uses ONNX Parakeet. (Windows and Linux have their own guides.) You need two free developer tools. Open Terminal (press ⌘Space, type “Terminal”) and run:

xcode-select --install

That installs Apple's Command Line Tools (a dialog asks you to confirm). Then install uv, the Python tool Chirp's server uses:

curl -LsSf https://astral.sh/uv/install.sh | sh
No full Xcode needed.

The Mac app is built with the Command Line Tools alone. You don't need Tailscale for the Mac on its own — only later, if you add a phone.

Install

  1. Get the code

    In Terminal, download Chirp and step into its folder:

    git clone https://github.com/araa47/chirp.git
cd chirp
  2. Run the installer 
    ./scripts/install-mac.sh

    It installs the Chirp server in your Application Support folder, builds and signs Chirp.app, copies it to your Applications folder in your home folder, and opens the model picker. macOS may ask you to approve the local signing identity — allow it, so the permissions you grant survive future updates.

This is a source install for now.

There’s no notarized download yet — a packaged Mac app is coming soon. This installer builds Chirp on your Mac from the code you just cloned. Prefer an agent to do it with you? Use the coding agent prompts. For every platform, see Get Chirp.

Choose a model

The Models on this Mac window opens by itself. You can find it again any time under Settings → Advanced → Manage Local Models…

  1. Download a speech model

    Parakeet v2 is the English default: MLX on Apple Silicon, ONNX on Intel. On Apple Silicon, pick v3 if you dictate in other languages. Downloads show progress and can be paused.

  2. Optionally, a clean-up model

    A small local language model can tidy your text afterwards. Qwen3 4B on MLX scored best in Chirp's tests; smaller ones are faster but miss more. On Intel Macs, built-in clean-up and Notes structuring use llama.cpp on CPU and can be slow. Dictation works without them. Turn clean-up off, or use an OpenAI-compatible local endpoint such as Ollama or LM Studio. Click Use Model to check it loads. You can skip this and add it later.

  3. Start the server

    Click Start Local Server. (After changing a model later, use Apply & Restart Server — downloading alone never swaps the running model.)

Grant two permissions

The Set Up Chirp window walks you through it, with its steps listed on the left: Welcome, Microphone, Accessibility, Chirp server and Try it. Each step turns green the moment you grant access in System Settings → Privacy & Security. The last step tries a dictation, and Open Notes takes you to the notes library.

  • Microphone — so Chirp can hear you. The mic is only open while you dictate.
  • Accessibility — so Chirp can type into the app you're using. Without it, Chirp copies the text and you press ⌘V yourself.

Chirp does not need Input Monitoring. If the hotkey doesn't respond right after granting Accessibility, quit and reopen Chirp from the menu bar.

Dictate

  1. Click into any text field

    Notes, Mail, Slack, a browser — anywhere you can type.

  2. Hold Right ⌥ Option and talk

    That's the Option key on the right of the space bar. Let go to finish, or tap it once to talk hands-free. The Left Option key still types é and works in other apps' shortcuts. A small panel appears at the bottom of the screen with rippling rings and what Chirp hears.

  3. Pause, and it's typed

    Chirp stops after about two seconds of quiet (or tap the key again). Esc cancels and nothing is inserted.

Prefer another key? In Settings → Dictation pick a shortcut such as ⌃⌥Space, or record your own. Right ⌥ needs Accessibility, which Set Up Chirp asks for; ⌃⌥Space does not. Switch the mode to Hold to talk if you only want to hold.

Longer dictation: rolling segments keep one dictation going for about 10 minutes. The next segment captures while the previous one finishes; the results land in order. Auto-stop ends hands-free dictation when you pause, with a configurable Stop after interval. Holding the key keeps listening until you release it. Turn on Spoken commands in Settings → Dictation to turn a trailing “new line” or “new paragraph” into a line break.

Turn on clean-up (optional)

If you downloaded a clean-up model, open Clean-up in the menu-bar menu and tick Clean up Text. Chirp then removes fillers and stutters and fixes punctuation before inserting, using the model on your Mac.

The model unloads after a few idle minutes, so the first clean-up after a pause waits while it loads again. To skip that wait, turn on Keep clean-up ready in Settings → Clean-up: the model stays in memory (about 2.6 GB of RAM for Qwen3 4B) and clean-up starts instantly. Chirp suggests this once, the first time a dictation waits for the model.

Intel Mac? Built-in clean-up and Notes structuring run on CPU and can be slow. You can leave clean-up off and dictate normally, or use an OpenAI-compatible local endpoint such as Ollama or LM Studio. Turn Structure notes off to use Notes as a plain transcript.

  • Styles change the tone: chat, email, code and notes. Chirp picks one by app — Mail gets email, Terminal gets code — and you can edit the list in Settings → Clean-up.
  • Use raw: changed your mind? For five seconds after a cleaned dictation, ⌃⌥Z puts back exactly what you said.

Teach Chirp your words

Settings → Dictation → Learn from my edits learns names and technical words from small corrections to a verified insertion. Make the same fix twice, or choose Teach Chirp… in Dictation history to teach it once. Learned lets you review, approve, undo or delete items. Learning needs dictation history; paste insertions and password fields are excluded. Learned items stay encrypted on this Mac and active terms go with dictation to your own Chirp server and any configured clean-up endpoint.

Private session, in the menu bar or Dictation settings, skips new history, learning and learned context. It ends when the screen locks, after one hour or when Chirp quits. Existing history stays. New Note (⌘N in Notes) creates a blank typed note; ⌃⌥N starts a new recording.

Next: press ⌃⌥N to start a note. See Take notes.

If something's off

  • “Copied — press ⌘V” instead of typing: Accessibility isn't granted yet (or the app only accepts pasting). Grant it and reopen Chirp.
  • “Server unreachable” in the menu: open Settings → Advanced and click Copy Doctor Command, then paste it into Terminal for a check-up.
  • “No microphone signal”: check the Microphone row in the menu. A Mac mini has no built-in mic.
  • A badge on General in Settings: a permission is missing. The page has a Fix… button for it.
  • Nothing in a password field: on purpose — Chirp never types into secure fields.
